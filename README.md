How much crossing weight can an internal coloring leave available at every exceptional vertex? The paper gives recoloring bounds with prescribed class sizes, computes the exact deficit of a completion constrained to blocks, and gives a 1-factorization criterion using weighted Hall reserves, a hypergraph nibble and spectral repair. In the sparse grid example, a deterministic construction gives an explicit threshold and the same multigraph fails the rectangle criterion on its given cut.

El artículo estudia el recoloreo ponderado con tamaños de clase prescritos, el déficit exacto de completación por bloques y un criterio de 1-factorización con reservas ponderadas y espectrales. La rejilla dispersa separa el nuevo resultado del criterio de rectángulos sobre un corte fijo.

This preprint is an independent work.
